# Security

## Reporting a vulnerability

Please report it privately, through
[GitHub's private vulnerability reporting](https://github.com/Masterplanner25/aindy-runtime/security/advisories/new).
Don't open a public issue or pull request for it.

Include the version you tested, what you did, and what you could reach that you shouldn't have.

## Supported versions

Fixes ship in a new release on the current line. They are not backported, so the supported version
is the newest one on [PyPI](https://pypi.org/project/aindy-runtime/).

## Published advisories

Listed on the repository's
[security advisories page](https://github.com/Masterplanner25/aindy-runtime/security/advisories).
