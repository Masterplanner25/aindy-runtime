You are performing a SYSTEM CAPABILITY CLASSIFICATION.

DO NOT restate what exists.
ASSUME the system summary is already known.

Your job is to answer:

"What level of system is this REALLY?"

---

## TASK

Classify the system along these axes:

1. Execution Capability
   - simple API
   - workflow engine
   - orchestration system
   - autonomous system

2. Reliability Level
   - best effort
   - deterministic
   - production-stable
   - fault-tolerant

3. Autonomy Level
   - manual triggers only
   - assisted automation
   - semi-autonomous
   - autonomous

4. Developer Leverage
   - toy
   - internal tool
   - platform
   - extensible ecosystem
