You are identifying the SYSTEM LIMIT.

---

## TASK

Answer:

"At what point does this system stop being useful?"

---

Define:

1. Max workload it can realistically handle
2. Max complexity of workflows
3. Max number of users
4. Max level of automation before failure

---

Then identify:

### Hard Boundary

The exact point where the system breaks or becomes unreliable.

---

### Root Cause

The underlying reason for that boundary:
- architecture
- infra
- missing system
- external dependency

---

### Upgrade Path

What ONE change would extend that boundary the most?
